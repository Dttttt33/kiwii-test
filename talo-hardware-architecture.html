Kiwii Hardware × Land Architecture

问题四：两个硬件和 app 的接口，和 Unity 的 scope

🎯 公平性原则

硬件不增加资源的「量」和养成进度。没硬件 → 量。有硬件 → same 量 + 更高质量 + 独占 asset。

🔌 管子原则

Power 和 Balance 是独立游戏产品。和 Land 之间只有一根数据管子。管子两端各自可以无限扩展复杂度。

🌍 同一世界

三个产品共享同一个世界观。Power 是你走进地里干活的近景。Land 是退后一步看全貌。场景风格对齐。

    Unity Scope 分工

    Unity · Land 端

    • 5种地形 3D 场景
    • 栏位视觉（空/生长中/成熟）
    • 通用配方 × 地形 = 产出模型
    • 品质差异视觉（普通 vs 精炼）
    • Recover 环境效果（天气/光照/动物）
    • 硬件独占 asset 的 3D 模型
    • 朋友来访的视觉（脚印/痕迹）

    Unity · Power 端

    • 5种农场场景（和 Land 地形对齐）
    • 农活动作动画（翻地/播种/浇水/收割）
    • 作物生长 + 收割动画
    • Power 自己的游戏系统（独立扩展）
    • 工具/升级的视觉
    • session 结束收割动画

    App Native UI

    • 背包/资源管理界面
    • 栏位分配交互（tap 选择）
    • 社交界面（朋友/逛地/送礼）
    • 数据卡展示 + 分享
    • 推送和通知
    • "我的"页面（运动数据+趋势）
    • 设置/同步/硬件连接

    Power 的可扩展性

    Power 是独立游戏，有自己的深度。以下是可扩展方向（不影响 Land）：

    🌾
    作物系统
    季节轮换、解锁新品种、杂交育种、稀有作物
    🗺️
    土地扩张
    开垦新地块、解锁新区域、不同区域种不同东西
    🔨
    工具升级
    坚持训练 → 工具升级 → 同样rep效率更高/画面更好
    🌦️
    天气事件
    随机旱灾（多做几组）、丰收季翻倍、台风（限时挑战）
    👤
    NPC / 剧情
    角色订单（"帮我种3行"=3组深蹲）、解锁故事线
    🏆
    成就系统
    累积解锁、里程碑奖励、装饰物、农场等级
    👥
    多人合作
    同时 session → 一起种一片大田、合作收割
    🎪
    轮作策略
    不同动作组合 = 不同种植策略 → 不同产出配比

    📐 双方需要对齐的

    ① 5种地形的美术风格
    ② Power 独占 asset 的视觉设计
    ③ 管子的数据格式
    ④ "精炼"品质的视觉表达标准

    🔓 Power 可以自己决定的

    游戏深度、关卡设计、作物系统、NPC剧情、工具升级、天气机制、成就——全部独立，不需要 Land 配合。

    🔓 Land 可以自己决定的

    生态系统规则、社交玩法、新配方、季节事件、新地形——全部独立，不需要 Power 配合。
