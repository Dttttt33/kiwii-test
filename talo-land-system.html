从 Power 出发 → Land 该长什么样

每个 Power 世界推导出一套 Land 设定：Move 是什么、Build 是什么、5 种人格分别是什么

POWER 01 异星生存食堂
Power 里你在做：水培泵压、搬培养缸、接管道、搅藻池、撒种采摘、做补给餐
核心感受：在不适合生存的地方，一点一点造出一个能活的系统

这个 Power 推导出的 Land 世界

你的 Land 是一颗刚被唤醒的星球。一开始什么都没有——灰色的地表、稀薄的空气、沉默的石头。

你的运动让这颗星球一点一点活过来。先是空气有了氧、然后地面出现第一抹绿、然后水开始流、然后第一个生物出现。

这个 Land 的叙事是：从零到有的造星过程。别人来你的地，看到的是"这颗星球被这个人养活了"。

Move 看起来是
生命扩散
氧气圈扩大、绿色从中心向外蔓延、新区域被"激活"变得可以生存。从灰色变成有颜色。
Build 看起来是
系统成熟
植物从幼苗变成完整生态、结构从临时变成永久、系统从脆弱变成自循环。一个东西从"勉强活着"变成"稳定运行"。
Recover 看起来是
变异进化
已有生物出现适应性变异——发光、变色、形态更复杂。整颗星球的"进化速度"在加快。
这个 Land 里的五种人格
🫁
造氧者
匹配：稳定输出型、享受基础建设、不急于看到结果
你的星球以"空气"为核心。第一优先是让大气变得可呼吸。你的地远看有一层淡绿色的雾——那是氧气在扩散。
Move → 氧气圈径变大，更多地表从"死"变成"可生存"
Build → 产氧植物从小苗变成巨型制氧林，空气浓度可视化变深
💧
引水者
匹配：路径思维、喜欢规划流动、享受"通了"的快感
你的星球以"水"为核心。第一优先是让液态水出现和流动。你的地有越来越复杂的水系——溪、湖、瀑布、地下河。
Move → 水路延伸到新区域，干涸地带出现第一滴水
Build → 水系从细流变成河、从浅洼变成深湖、瀑布落差变大
🌱
播种者
匹配：多样性导向、喜欢收集、享受"又多了一种"
你的星球以"物种多样性"为核心。第一优先是让尽可能多种类的生物出现。你的地像一个快速进化的实验场。
Move → 新物种出现（植物/菌/小生物），地表越来越杂越来越满
Build → 已有物种成熟到可以繁殖的阶段、形成稳定种群
🏗️
建站者
匹配：结构思维、喜欢搭系统、享受"跑通了"
你的星球以"基础设施"为核心。第一优先是让系统互相连通。你的地有管道、温室、储能装置——人造的和自然的混合。
Move → 新节点出现（小温室/储水站/能量桩），网络扩展
Build → 节点升级，从临时变永久、从单机变联网、从手动变自动
🔬
变异者
匹配：猎奇型、喜欢稀有、享受"没人见过这个"
你的星球以"异变"为核心。第一优先不是数量而是极端形态。你的地上东西不多，但每一个都很怪很美很稀有。
Move → 新变异位点出现（可能变异的"热点"区域增多）
Build → 已有变异体稳定下来、从偶发变成可繁殖的稳定种
POWER 02 孤独灯塔食堂
Power 里你在做：翻盐碱地、拉渔网海藻、搬挡风石、搅汤揉面、采摘、递餐、点灯
核心感受：在雾海孤岛上经营一间食堂，为迷路的人提供热饭和方向

这个 Power 推导出的 Land 世界

你的 Land 是一座雾中慢慢显现的岛。一开始被浓雾完全包围，什么都看不清。

你的运动让雾一层一层散开——先看到脚下的地，然后是近处的海岸线，然后是远处的礁石，最后是海平线和星空。

这个 Land 的叙事是：雾散了，世界亮了。别人来你的地，看到的是"这个人的岛越来越清晰了，灯塔越来越亮了"。

Move 看起来是
雾散/可见范围扩大
雾退一圈，新的区域从模糊变清晰。海岸线露出更多、远处的岛变得可见。你的世界在"被看见"。
Build 看起来是
建筑/结构从废墟中修复
灯塔加一层、食堂多一面墙、栈桥延伸一段、挡风墙变高。已有的废墟从破烂变成完整变成美。
Recover 看起来是
光变暖/旅人来访
灯塔的光从冷白变暖黄、食堂窗户透出暖光、偶尔有旅人/候鸟/海兽来访留下痕迹。
这个 Land 里的五种人格
🔦
守灯人
匹配：责任感强、稳定输出、享受"被需要"
你的岛以灯塔为核心。灯塔在一层一层变高变亮——从废墟里修出来的光，是整个岛的支柱。
Move → 灯光照射范围变远，照亮更多海域和暗礁
Build → 灯塔加层变高、结构更稳、光更亮更远
🍲
煮汤人
匹配：关系导向、温暖、享受"有人来了"
你的岛以食堂为核心。食堂越来越完整——从一口锅变成有桌椅、有菜单、有屋顶的温暖空间。
Move → 食堂周围出现更多配套——菜园/晾衣绳/香草架，生活气息扩散
Build → 食堂本身变大变完整，厨房设备增加，能做的菜变多
🌊
探雾人
匹配：好奇心驱动、喜欢发现、享受"又看到新东西了"
你的岛以"散雾"为核心。你最关心的不是修什么——是看到更多。雾每退一点你就兴奋。
Move → 雾退更快更远，新区域被照亮/显现
Build → 已显现区域里的细节变丰富——不是更大，是更清晰更真实
🐚
拾潮人
匹配：收集癖、观察型、享受"潮水带来了什么"
你的岛以海岸线为核心。你不急着修灯塔——你每天在意的是退潮后沙滩上多了什么。
Move → 海岸线变长、潮池变多、能捡到的东西种类增加
Build → 收集到的东西从散落变成陈列——贝壳墙、漂流木架、海玻璃马赛克
🐦
候鸟站
匹配：社交能量型、喜欢热闹、享受"来人了"
你的岛以"来访者"为核心。你修的一切都是为了让更多人/鸟/兽愿意来、愿意留。
Move → 可停靠的位置增多——码头/鸟架/浅滩台阶
Build → 来访者的种类升级——从虫到鸟到大型海兽到人类旅人
POWER 03 四季山间民宿
Power 里你在做：翻地插秧、割稻拔草、扛粮立竿、采茶采果、捣年糕烤团子、挂灯笼摇铃
核心感受：在四季分明的山间民宿里，用料理和节日把人情味找回来

这个 Power 推导出的 Land 世界

你的 Land 是一座有四季流转的山村。它真的在随时间变——春天有樱花和新芽、夏天有浓绿和蝉、秋天有红叶和稻黄、冬天有雪和炉火。

你的运动让这个村子越来越有人住过的痕迹——从荒废的旧村变成有烟火气的活地方。田在被种、灯在亮着、路在被走。

这个 Land 的叙事是：一个冷清的山村被你一点一点暖回来。别人来你的地，能感觉到"有人在这里认真过日子"。

Move 看起来是
生活半径变大
可走的路变长——从民宿到田、到神社、到温泉、到竹林、到集市。地图上亮着的区域越来越多。
Build 看起来是
房子/田/设施修复完善
民宿从破旧变成干净、田从荒草变成整齐、设施从坏掉变成能用。每一样东西在被"修好"。
Recover 看起来是
季节更分明/节日出现
四季变化的幅度更大、颜色更饱和。恢复好时触发节日事件——祭典、集市、花见、雪祭。
这个 Land 里的五种人格
🌾
田主
匹配：踏实务实、享受劳动成果、有耐心等收成
你的村以稻田为核心。最显眼的是一片越来越大越来越整齐的田——四季最明显（插秧/抽穗/金黄/雪覆）。
Move → 田的面积变大，从一块变成一片梯田
Build → 田的设施完善——水渠通了、谷仓建了、晒场铺好了
🏮
宿主
匹配：关系导向、好客、享受"招待人"的快乐
你的村以民宿为核心。你的民宿在变大——从一间屋变成有庭院、有茶室、有展望台的完整旅馆。
Move → 客房增多、能接待的客人类型增加
Build → 民宿建筑变精致——从修补变成扩建、从简陋变成有风格
🍵
料理人
匹配：手艺型、讲究过程、享受"做出来了"
你的村以厨房/食堂为核心。你在意的不是房子多大——是能做的菜有多少种、食材有多丰富。
Move → 食材种类增加——菜园物种变多、能采集的区域变广
Build → 厨房设施升级——灶台变好、器具增多、能做的料理复杂度上升
⛩️
祭司
匹配：仪式感强、重视节奏/节日、精神性
你的村以神社和节日为核心。你的四季事件最丰富——别人的村可能只有春秋两个节日，你的每个月都有。
Move → 节日种类/数量增多、能参与的活动变多
Build → 神社/祭坛修复完善、节日规模变大（从一个人变成一群人）
🚶
散步者
匹配：慢节奏、不目标驱动、享受"路上"而非终点
你的村以"路"为核心。你不急着修民宿——你在意的是能走的小路有多长、经过多少风景。
Move → 小路延伸到更远——到山顶、到瀑布、到隐秘的花田
Build → 路两边的风景变密变好——从空荡变成有竹林/石灯/溪流/野花
POWER 04 小车厨房旅行记
Power 里你在做：搬土箱/提水桶、拉遮阳棚/固定支架、揉面翻锅切菜、撒种采摘、推车展摊
核心感受：开着小餐车走遍世界，把一路遇见的风景做成料理

这个 Power 推导出的 Land 世界

你的 Land 是一张不断展开的地图。不是一块固定的地——是一条路线。你的车在走，经过的地方都留下了痕迹。

你的运动让这条路越来越长、经过的地方越来越多。每到一个新地方就解锁一小块区域，上面留下你待过的痕迹——一个小摊、几盆植物、一群认识你的人。

这个 Land 的叙事是：一条越来越长的旅途，沿路全是你留下的气味。别人来你的地，看到的是"这个人走过好多地方"。

Move 看起来是
路线变长/新地点解锁
地图上新的一段路亮了，新的地点出现——海边小镇、山间村落、沙漠绿洲、港口集市。你到过的地方越来越多。
Build 看起来是
已到过的地方痕迹加深
你在某个地方留下的痕迹变重——临时小摊变成固定铺位、车顶花箱变成小花园、路人变成熟客。一个"路过"变成"驻扎过"。
Recover 看起来是
各地风味融合/独特料理
你做的料理开始出现"混合风味"——两个地方的食材组合出新东西。恢复好时解锁独特配方。
这个 Land 里的五种人格
🗺️
远行者
匹配：好奇心强、数量导向、享受"又解锁了一个新地方"
你的地图以"长度"为核心。你走过的路比谁都长，到过的地方比谁都多。每个地方只浅浅留痕就走了。
Move → 路线延伸极快、新地点解锁多
Build → 不深耕单点，但路线本身变得更"清晰"——标记/路标/通路质量
🏕️
扎营者
匹配：深度型、喜欢把一个地方经营透、不急着走
你的地图点不多，但每个点都很"厚"。你在一个地方待久一点——临时摊变成了小店，有了回头客。
Move → 单点周围可探索区域增多（镇上的巷子/附近的山）
Build → 单点设施从简陋变完善——从路边摊变成有招牌有桌椅的小餐厅
🧑‍🍳
融合料理人
匹配：创造型、喜欢混搭、享受"新组合"
你的地图以"食谱"为核心。你每到一个地方不是看风景——是收集食材和做法。你的价值是"别人组合不出来的菜"。
Move → 可获得食材种类增多（到新地方就解锁新原料）
Build → 食谱复杂度提升——从单一菜系到多地融合、从简单到精致
📸
记录者
匹配：审美型、重视展示、享受"别人看到我走过的路"
你的地图以"视觉"为核心。你在每个地方留下的痕迹很好看——像一本摄影集/旅行日记。
Move → 新的"画面"解锁——每个地点呈现为一帧很美的画
Build → 每帧画的细节/丰富度增加——从素描变成完整着色
🤝
结交者
匹配：社交驱动、关系导向、享受"认识了新朋友"
你的地图以"人"为核心。你每个地方最在意的是遇到了谁。你的路线上标记的不是地名——是人名。
Move → 遇到的人变多（NPC/路人/其他用户）
Build → 关系从"路人"变成"熟客"变成"朋友"，互动深度增加
POWER 05 城市屋顶生态合作社
Power 里你在做：搬花箱上楼、搭架子/拉管道、扛土袋、浇水撒种采摘、铺防水布展棚子
核心感受：在钢筋水泥的城市上方，搭出一个会生长的邻里厨房

这个 Power 推导出的 Land 世界

你的 Land 是一座正在被绿色侵入的城市。一开始是纯水泥灰——天台、管道、排风口、混凝土缝。

你的运动让绿色一点一点从缝隙里长出来、从屋顶蔓延到墙面、从一栋楼扩散到一个街区。人造和自然在混合。

这个 Land 的叙事是：城市正在被你亲手变绿。别人来你的地，看到的是"水泥森林里居然长出了这些"。

Move 看起来是
绿色蔓延到新楼/新区域
隔壁楼的天台也开始长东西了、墙面有藤了、阳台有花箱了。绿色从一个点扩散到一片区。
Build 看起来是
种植结构往上搭/系统变完整
从平面花箱变成垂直墙、从一层架子变成多层、从手动浇水变成自动灌溉。你的屋顶农园在"长高"。
Recover 看起来是
生态出现/动物来了
蜜蜂来了、蝴蝶来了、猫上来了、楼下的人来串门了。从"人造种植"变成"有了生态"。
这个 Land 里的五种人格
🌿
屋顶农夫
匹配：务实产出型、享受"种出来了就能吃"
你的城市以"产出"为核心。你的屋顶种的是菜——番茄黄瓜香草辣椒。实用、丰收、有烟火气。
Move → 种植面积扩大——从一个花箱到占满整个天台
Build → 产量/品种升级——从只种一种到多种轮作、从小收获到需要分给邻居
🏗️
架构师
匹配：系统思维、喜欢搭结构、享受"工程完成"
你的城市以"结构"为核心。你享受的不是种什么——是搭出越来越复杂的垂直种植系统。管道、架子、自动化。
Move → 系统覆盖到新楼栋（管道跨楼延伸、架子连通相邻屋顶）
Build → 单栋系统复杂度增加——层数变多、自动化程度变高
🐝
生态营造者
匹配：环保/自然导向、享受"生态回来了"
你的城市以"生态恢复"为核心。你不只种菜——你在引蜂、引蝶、做雨水循环、堆肥、造小湿地。
Move → 生物种类增加——新的虫/鸟/小动物出现在你的区域
Build → 生态链变完整——从"只有植物"到"有完整食物链在运转"
🍱
社区厨房
匹配：社交型、享受"分享/喂人"、邻里关系驱动
你的城市以"共享"为核心。你种出来的东西不是自己留——是做成便当/果酱/茶分给楼里的人。
Move → 能辐射的"邻居"变多——从同一层到同一栋到隔壁栋
Build → 共享设施变完善——从随手分到有固定取餐点/公告板/预约系统
🎨
绿化艺术家
匹配：审美驱动、视觉型、享受"好看比好吃重要"
你的城市以"美"为核心。你种的不是菜——是观赏植物、垂吊藤、花墙。你的楼在变成城市里最好看的那栋。
Move → 可视面积增加——从天台到外墙到窗台到地面，绿色铺满建筑表面
Build → 视觉密度/层次增加——从几盆花变成整面绿墙、色彩搭配变精致
